Buoyancy Laboratory

Buoyant force equals weight of displaced fluid. Compare object density to fluid density to predict float, sink, or suspend.

Controls
What to notice
Fully submerged: F_b = ρ_fluid · V · g. If ρ_object < ρ_fluid the object floats with only part submerged.
  • Same volume, denser fluid → larger F_b.
  • Apparent weight = true weight − F_b.

Problem tip
