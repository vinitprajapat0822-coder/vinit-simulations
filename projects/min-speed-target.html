Key Formulas

Trajectory equation
y = x tanθ − (g x² / 2u²) (1 + tan²θ)
Minimum speed to pass through (x, y)
umin = √[ g ( y + √(x² + y²) ) ]
Corresponding optimal angle
θopt = arctan( (y + r) / x ) where r = √(x² + y²)

Detailed Analysis

1. What does “minimum speed” mean?

For a fixed target (x, y) there is a continuous range of speeds that can hit the point (by choosing suitable angles). The smallest of those speeds is called umin. Below this speed no real angle exists that makes the trajectory pass through the target.

2. Geometric insight

  • The point (x, y) lies at a distance r = √(x² + y²) from the origin.
  • The formula umin = √[g(y + r)] comes from the condition that the discriminant of the quadratic in tanθ becomes zero.
  • At this critical speed only one angle works — the trajectory just “touches” the required condition.

3. Two possible angles (when u > umin)

When the launch speed is greater than the minimum, two different angles can hit the same point (high trajectory and low trajectory). The simulation shows the lower-angle path for the current speed.

4. Special cases

  • If the target is on the ground (y = 0), then umin = √(g x) and θ = 45°.
  • If the target is directly above the origin (x → 0), the formula still holds but the angle approaches 90°.

5. How to use this lab

  • Move the Target X / Y sliders to any point.
  • Click Use Minimum Speed — the speed slider jumps to the exact theoretical minimum and the green path appears.
  • Increase the speed above minimum and press Play to see the actual flight.
  • Watch the Status indicator: it tells you whether the current speed can reach the target or not.
