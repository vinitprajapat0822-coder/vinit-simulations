ANGULAR MOMENTUM

Angular Momentum Laboratory

For a rigid body about a fixed axis, L = Iω. Rotational KE is ½Iω². If torque is zero, L is conserved.

Controls
What to notice
Ice skater pulls arms in → I decreases → ω increases so that L = Iω stays roughly constant (small external torque).
  • L and ω share the same axis direction (right-hand rule).
  • KE is not conserved when a skater pulls arms in — muscle work changes energy.
