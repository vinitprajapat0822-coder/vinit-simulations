Radioactivity & Half-life Laboratory

Exponential decay N = N₀ e^{−λt}. Half-life is the time for N to fall to half — independent of N₀.

Controls
What to notice
After one half-life, half the nuclei remain; after two, one quarter — the curve never hits exactly zero in the ideal model.
  • λ = ln2 / T½.
  • Activity A = λN decreases with the same half-life.

Theory & formulas

Decay law

N = N₀ e^{−λt}
λ = ln2 / T½
A = λN

Problem tip

Number of half-lives n = t/T½ → N = N₀ / 2ⁿ.
